# Маніфест контрольованого розгортання

Цей пакет підготовлено для внесення до репозиторію `ChernyshDarisha/manus-debt-challenge` після відновлення автентифікації GitHub. Він не виконує зовнішніх запитів, не сканує персоналії автоматично та не подає звернення до органів влади.

| Джерело в пакеті | Цільовий шлях у репозиторії | Призначення |
|---|---|---|
| `src/research/__init__.py` | `src/research/__init__.py` | Python-пакет дослідницького компонента |
| `src/research/public_source_registry.py` | `src/research/public_source_registry.py` | Внутрішня модель індикаторів, валідація й SHA3-256 походження джерела |
| `schemas/public_source_risk_record.schema.json` | `schemas/public_source_risk_record.schema.json` | Контракт даних для API, БД та журналу доказів |
| `docs/INTEGRATION.md` | `docs/public-source-research-integration.md` | Архітектурні обмеження, потік рев’ю та критерії приймання |
| `test_registry.py` | `tests/test_public_source_registry.py` | Регресійний тест безпечних станів |

## Послідовність внесення

Спочатку додайте файли до окремої гілки, запустіть `python3 tests/test_public_source_registry.py` або адаптуйте тест до наявного тестового раннера. Далі додайте перевірку JSON Schema до CI. Лише після цього підключайте контролер API та UI в стані `internal_review` за замовчуванням.

Будь-який механізм зовнішньої публікації, подання скарги або формування персоналізованого досьє повинен залишатися вимкненим, поки немає окремого підтвердження користувача, юридичного огляду та другої перевірки джерела.
